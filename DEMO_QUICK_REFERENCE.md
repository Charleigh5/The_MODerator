# Interactive Demo - Quick Reference Guide

## 🎬 Starting the Demo

1. Look for the **"🎬 Start Demo"** button in the bottom-right corner
2. Click it to begin the interactive walkthrough
3. The first fly-out panel will appear at the top of the screen

## 📖 Using the Fly-Out Panel

Each step shows a detailed explanation panel with:

### Header
- **Step number** in a maize circle (e.g., "5")
- **Step title** (e.g., "Step 5: Stretch Ideas")
- **Progress** (e.g., "5 / 17")

### Content
- **Detailed Explanation** - Full walkthrough of what's happening
- **Agent Action** - What CODEWRIGHT is doing behind the scenes
- **Why This Matters** - Why this step is important

### Navigation
- **← Previous** - Go back to review earlier steps
- **Skip** - Jump to next step without executing action
- **Next Step →** - Proceed when you're ready

## 🎯 Demo Steps Overview

### Phase 1: Getting Started (1-3)
1. Welcome - Introduction to workspace
2. Upload Requirements - How to provide specs
3. Describe Your MOD - Type your brief

### Phase 2: AI Analysis (4-5)
4. Send Your Brief - Submit to CODEWRIGHT
5. Agent Analyzes - AI processes request

### Phase 3: Enhancement (6-7)
6. Stretch Ideas - AI-suggested features
7. Select Stretch Ideas - Choose enhancements

### Phase 4: Refinement (8-10)
8. Lock In Choices - Confirm selections
9. Q&A Phase - Detailed questions
10. Answer Questions - Provide preferences

### Phase 5: Pattern Learning (11-12)
11. Pattern Vault - Explore proven MODs
12. Pull Patterns - Learn from existing code

### Phase 6: Compilation (13-14)
13. Compiling Your MOD - Generate code
14. Play Sheet - View completed MOD

### Phase 7: Testing & Export (15-17)
15. Build & Test - Verify MOD works
16. Export Your MOD - Download final file
17. Demo Complete - Congratulations!

1. **Read each explanation** - Don't rush through

### Common Questions

**Q: Can I pause the demo?**
A: Yes! Just don't click "Next Step" until you're ready.

**Q: Can I go back?**
A: Yes! Click "Previous" to review earlier steps.

**Q: What if I don't understand?**
A: Read the detailed explanation. If still unclear, skip and try again later.

**Q: Can I restart?**
A: Yes! Click "Start Demo" again anytime.

**Q: Do I have to complete all steps?**
A: No! You can skip any step or exit early.

## 🐛 Troubleshooting

### Demo Won't Start
- Refresh the page
- Check browser console for errors
- Try a different browser

### Fly-Out Not Showing
- Check if demo is active (look for progress indicator)
- Refresh the page
- Clear browser cache

### Cursor Not Moving
- Check if target element exists
- Refresh the page
- Try clicking "Next Step" manually

### Navigation Not Working
- Check if buttons are clickable
- Refresh the page
- Try keyboard navigation (Tab + Enter)
