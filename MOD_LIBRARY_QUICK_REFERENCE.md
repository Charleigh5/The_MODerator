# Mod Library Browser & Code Viewport - Quick Reference

## 🎯 Quick Start

### Browse Vault Mods
1. Click **VAULT** button (green badge "9") in TopBar
2. Search or browse mods
3. Click a mod to see details
4. Choose "Use" or "Modify"

### Use a Mod
1. Open Mod Library Browser (VAULT button)
2. Find a mod you like
3. Click "Use This Mod"
4. Patterns are imported to your knowledge base
5. Start building on top of it

### Modify a Mod
1. Open Mod Library Browser (VAULT button)
2. Find a mod to customize
3. Click "Modify This Mod"
4. Code Viewport opens showing the code
5. Start customizing

## 🎨 Code Viewport Features

### What You See
- **Line Numbers**: Left side

- **Modified Lines**: Green dots

- **File Name**: Top header
- **Stats**: Bottom footer

## 💡 Tips & Tricks

### Finding the Right Mod
1. **Start with ratings**: Look for 4.5+ stars
2. **Check reliability**: 90%+ is excellent
3. **Read reviews**: See what users say
4. **Review pros/cons**: Know the trade-offs
5. **Check warnings**: Be aware of issues

### Using Mods Effectively
1. **Read first**: Understand before using
2. **Start simple**: Don't modify everything at once
3. **Test often**: Verify after each change
4. **Save versions**: Track your changes
5. **Learn patterns**: Understand the code structure

### Code Viewport Tips
1. **Watch the generation**: Learn as code appears
2. **Note modified lines**: See what changes
3. **Understand syntax**: Use highlighting to learn
4. **Track files**: Know what's being modified
5. **Use as reference**: Come back to understand code

## 🚀 Common Workflows

### Workflow 1: Learn from Existing Mods
```
1. Open VAULT
2. Find highly-rated mod (4.5+ stars)
3. Read description and reviews
4. Click "Use This Mod"
5. Study the patterns in knowledge base
6. Create your own mod based on it
```

### Workflow 2: Customize Existing Mod
```
1. Open VAULT
2. Find mod to customize
3. Click "Modify This Mod"
4. Code Viewport opens
5. Study the code
6. Make small changes
7. Test after each change
8. Save to library
```

### Workflow 3: Combine Multiple Mods
```
1. Open VAULT
2. Find 2-3 complementary mods
3. "Use" each one (imports patterns)
4. Create new mod combining patterns
5. Test thoroughly
6. Save to library
```

## 📊 Mod Ratings Guide

### Star Ratings
- ⭐⭐⭐⭐⭐ (5.0): Exceptional, must-use
- ⭐⭐⭐⭐½ (4.5-4.9): Excellent, highly recommended
- ⭐⭐⭐⭐ (4.0-4.4): Very good, solid choice
- ⭐⭐⭐½ (3.5-3.9): Good, some issues
- ⭐⭐⭐ (3.0-3.4): Average, use with caution
- ⭐⭐ (2.0-2.9): Below average, not recommended
- ⭐ (1.0-1.9): Poor, avoid

### Reliability Scores
- 95-100%: Rock solid, production-ready
- 90-94%: Very reliable, minor issues
- 85-89%: Reliable, some edge cases
- 80-84%: Mostly reliable, test thoroughly
- <80%: Use with caution, may have bugs

## 🔧 Troubleshooting

### Can't Find a Mod
- Try different search terms
- Check category filter
- Browse all categories
- Check if mod exists in data

### Code Viewport Won't Open
- Ensure you clicked "Modify This Mod"
- Check browser console for errors
- Try refreshing the page

### Patterns Not Importing
- Verify mod has patterns
- Check knowledge base panel
- Try using the mod again

### Code Not Animating
- Check if generation is active
- Verify code is being passed
- Check animation settings

### Common Questions

**Q: Can I use multiple mods together?**
A: Yes! Use multiple mods to import their patterns, then combine them.

**Q: Can I edit mods after using them?**
A: Yes! Click "Modify This Mod" to open the Code Viewport.

**Q: Where are mods stored?**
A: Mods are in `src/data/modLibrary.ts`. Your modifications are saved to your mod library.

**Q: Can I add my own mods to the vault?**
A: Future feature! For now, save to your personal mod library.

**Q: How do I know which mod to use?**
A: Check ratings (4.5+), reliability (90%+), and read reviews.
